# HouseEvaluator v2 화면

표준 HTML/CSS/JavaScript로 구현한 한국어 입력·근거 화면입니다. 빌드 및 npm 설치가 필요하지 않습니다. v2 서버가 제공하는 `/frontend/v2/`를 엽니다. 정적 파일 서버만 실행하면 API가 없으므로 자료 연결 오류를 표시합니다.

## 연결하는 API

- `GET /api/v2/capabilities`: 실제 자료 연결 상태와 합성 시연 가능 여부.
- `GET /api/v2/stations?city=tokyo|osaka|fukuoka&mode=market|demo`: 공급 자료에서 확인한 역 선택 목록. 화면에는 역 이름과 행정구역을 표시하고 정규 ID는 내부 값으로 유지합니다.
- `POST /api/v2/evaluate`: `{subject, mode: "market" | "demo"}`. 미상 특성은 `null`로 전송합니다. 관리비를 모를 때 0으로 보정하지 않습니다.
- `GET /api/v2/demo-subject?city=tokyo|osaka|fukuoka`: 사용자가 합성 시연을 켠 경우에만 호출합니다.
- `POST /api/v2/costs`: 확인한 월세·관리비와 개별 비용을 독립적으로 계산합니다.

사용자는 공급 자료에 있는 역을 선택하며, 코드를 직접 입력하지 않습니다. 선택하면 역 이름과 행정구역을 채우며 행정구역은 실제 매물 주소에 맞게 수정할 수 있습니다. 도시·모드 변경 시 이전 역 선택을 지우고 해당 목록을 다시 불러옵니다. 역 목록이 없으면 가격 비교를 비활성화하고 비용 계산은 유지합니다. 합성 예시는 역 목록을 받은 뒤 정확히 일치하는 항목을 선택합니다. 합성 시연에서 실제 모드로 돌아가면 합성 ID를 포함한 예시와 결과·비용 입력을 초기화합니다. 개인정보나 입력값을 브라우저 저장소에 보관하지 않습니다.

## 표시 원칙

- 서버가 반환한 매물·표본·시각·중앙값·사분위·조건 완화 기록과 판정 보류 사유를 표시합니다.
- `null` 가격과 미상 시각을 0원·현재 시각으로 대체하지 않습니다.
- `comparable`이고 합성 데이터가 아니며 방향 판정이 있는 경우만 높은/비슷한/낮은 표현을 사용합니다.
- 합성 입력·결과에는 항상 `합성 데이터 시연 · 실제 시세 아님`을 표시합니다.
- 서버 문자열은 `textContent`로 렌더링하며, 원문 링크는 자격정보 없는 HTTPS URL만 허용합니다. 로컬 호스트와 사설 IP 링크도 제외합니다.
- 대기는 실제 요청 생명주기와 연결됩니다. 취소·오류·제한 시간을 처리하고 이전 응답이 새 입력을 덮지 않게 요청을 식별합니다.
- 비용 입력이 바뀌면 이전 비용 결과를 지웁니다. 비용 계산은 시장 대표가격을 변경하지 않습니다.

UI를 통한 실제 시장 검증 완료를 의미하지 않습니다. 데이터 공급 계약과 도시별 검증은 `DEVELOPMENT_PHASES.md`의 별도 출시 기준을 따릅니다.
