# 공급사 문의 문안 — 검토용, 미발송

작성·공식 창구 확인: **2026-09-13**. 아래 `【要記入：…】`는 사용자가 사실대로 채워야 하는 자리다. 회사·사업자 등록·중개 자격·거주지·연락처를 임의로 만들지 않았다. 이 문서는 발송 가능한 초안이며 문의 제출, 개인정보 동의, 계약 수락은 하지 않았다.

**공급사 없이 개발을 진행한다는 현재 사용자 지시에 따라 문의 실행은 보류했다. 이 문안은 향후 선택용 참고 자료다. 지금 발신자 정보 기입이나 발송 승인을 요청하지 않는다.**

먼저 한 곳에 맞는 문안을 골라 이름·실제 계약 주체·이메일을 채운다. 전화번호가 필수인 문의 양식에는 실제 번호를 사용한다. 개인 프로젝트이면 회사명 칸에도 그 사실을 명시하고, 법인만 접수하는 경우 개인 신청 가능 여부를 먼저 확인한다. API 키·계정 비밀번호·기존 공급 자료는 첫 문의에 첨부하지 않는다.
