## 실제 브라우저 확인

Codex 브라우저로 로컬 서버 `/frontend/v2/`를 열어 조작했다.

- 기본 실제 모드: 시장 자료 미연결, 역 목록 없음, 비교 버튼 비활성화. 비용 계산은 별도로 사용 가능.
- 명시적인 합성 시연: 역 이름 선택 후 예시 입력. 도쿄/오사카/후쿠오카의 합성 대표가격은 각각 94,500/76,500/64,500엔이고 각 24호실·12건물. 실제 시세·높음/낮음 판정으로 표시하지 않음.
- 표: 실제 응답의 조건 차이와 모집 확인 시각, 동일 건물 번호, 통계 반영 비중 4.17% 표시. 역·호실 코드를 일반 사용자의 주요 입력/표제로 노출하지 않음.
- 관리비를 키보드로 지우면 기존 결과가 숨겨짐. 다시 평가하면 가격·분포 미산출과 관리비 미상 사유가 표시됨.
- 비용 사례: 월세 60,000, 관리비 5,000, 매월 추가 1,000, 입주 청구 300,000, 그중 선납 65,000·환급성 보증금 60,000, 퇴거 30,000, 갱신 0, 할인 10,000엔. 보증금 전액 환급 가정으로 6/12/24개월 비용 각각 591,000/987,000/1,779,000엔. 입주 현금은 300,000엔으로 별도 표시.
- 실제 모드로 돌아가면 예시 월세·역·호실, 비교 결과, 비용 결과와 합성 배너 초기화.
- 390×844 모바일에서 전체 페이지 가로 넘침 없음. 큰 비교 표는 자체 영역에서 가로 스크롤. 입력과 결과 글자가 겹치지 않음. 검증 후 뷰포트 설정 원복.
- 브라우저 콘솔 오류·경고 없음. 표시 수정 후 새로고침하여 재확인.
