# 실제 공급 확보: 문의 대상과 첫 협상안

확인일: **2026-09-13, Asia/Seoul**. 아래는 공식 서비스·공식 발표·공식 문의 창구를 읽어 선정한 후보이다. 문의, 회원 가입, 샘플 신청, 견적 수락, 계약 체결은 실행하지 않았다. 공개 페이지에서 HouseEvaluator에 무료로 제공되는 현재 모집 호실 피드와 소비자 비교·표시·저장 권리를 함께 확인한 후보는 없다.

**현재 개발 방향은 사용자의 “공급사는 없다는 전제로 만들자” 지시에 따라 공급사 없이 사용하는 비교 기능이다. 이 문서는 향후 자동 갱신 데이터가 필요할 때 참고할 선택지이며, 현재 개발의 선행 조건이나 문의 실행 지시가 아니다.**

향후 제휴를 선택한다면 첫 문의는 **TAKUTO에 오사카 단신자용 물건의 제한 실증을 제안**하고, 확장 경로는 **ITANDI에 개별 데이터 제휴 가능 여부를 문의**하는 순서가 적합하다. 이는 아래 사실을 근거로 한 개발팀의 판단이다. TAKUTO는 목표 조건과 가까운 관리 물건 및 모집 종료 연계 사례가 있고, ITANDI는 최근 실제 물건 데이터 연계 사례가 있다. 두 회사의 HouseEvaluator 대상 공급 의사·무료 조건은 아직 알 수 없다.

여기서 “공급사”는 반드시 유료 데이터 판매 회사를 뜻하지 않는다. 비교할 개별 매물 정보를 지속적으로 제공하고 그 상태를 설명할 수 있는 출처를 가리킨다. 사용자가 비교 대상 정보를 직접 제공하는 경로도 가능하며, 이를 시장 전체를 자동 조회한 결과와 구분해서 보여주면 된다.

| 경로 | 제공되는 것 | 최신성·권리의 확인 방식 |
|---|---|---|
| 직접 제휴 API | 약정한 범위의 매물 및 변경·종료 정보 | 제공 명세와 실제 상태 확인 시각, 앱에서 가능한 사용 범위를 확인한다. 비용은 계약마다 다르다. |
| 관리회사가 허용한 CSV/JSON 피드 | 직접 관리하는 물건의 전체 목록 또는 변경 자료 | 관리회사의 제공 권한·확인 주기를 합의한다. 무료 협력도 가능하지만 보장되지 않는다. |
| 사용자가 직접 입력하거나 제공한 비교 자료 | 사용자가 선택한 표본 안의 조건·가격 | 사용자가 확인한 시점과 출처를 표시하고, 표본 범위 내 상대 비교로 설명한다. 제공 사실만으로 자동 수집·재배포 허락이나 현재 모집 상태가 증명되지는 않는다. |

## 3. 향후 제휴를 선택할 때 사용할 최초 제안

발송 문안은 [일본어 문의 초안](SUPPLIER_INQUIRY_JA.md)에 준비했다. 아직 발송하지 않았으므로 응답 기한이나 협상 진행 상태를 만들지 않는다.

1. **범위:** TAKUTO에 오사카시 한 역 생활권의 일반 주거용 1R/1K, 무료·비공개 실증부터 가능한지 묻는다. 대안은 三好不動産의 후쿠오카 자사 관리 호실이다. 실제 관리 커버리지에 따라 역을 선택하며 특정 역의 물량을 가정하지 않는다.
2. **첫 자료:** 권리를 명시한 실제 10~30호실 샘플과 필드 사전, 완전 목록/부분 응답 구분, 종료·정정 예시를 요청한다. 이 수량은 파서·매핑 검사용 제안이며 가격 판정 승인 수량이 아니다. 민감한 개인정보·사진 없이 시작한다.
3. **기술 방식:** 공급자의 기존 CSV/JSON 출력이 있으면 그 방식에 맞춘다. 지속적 호실·건물 ID가 없다면 양측이 검수 가능한 매핑 자료를 합의한다. API 신규 개발비를 먼저 유발하지 않는다. 현재 반입기는 정규 JSON 완전 스냅샷을 받으므로 CSV 등은 실제 샘플에 맞는 어댑터가 필요하다.
4. **필수 계약 범위:** 비교 계산, 한국어 소비자 화면의 제한된 근거 행/원문 링크, 현재 DB 저장, 비공개 검증용 버전 아카이브, 백업, 계약 종료 시 삭제, 공급 변경 예고를 각각 확인한다. 공개 통계·모델 학습·전체 원문 재배포는 기본 요청에서 제외하고 필요할 때 따로 합의한다.
5. **0엔 조건:** 초기·월·호실·호출·갱신·표시·해지 비용과 최소 계약 기간을 모두 질문한다. 무료 샘플과 무료 운영은 별개다. 유료 견적은 기록만 하고 계약·발주는 사용자 결정 전 실행하지 않는다.
6. **다음 전환:** 유효한 허락과 샘플이 도착하면 공급 설정과 어댑터를 검수하고 실제 수신일을 기준으로 증거 수집을 시작한다. 기존 합성 운영 기록을 실매물 30일 기록으로 전환하지 않는다. 시장 검증 기준은 [MARKET_VALIDATION_V2.md](MARKET_VALIDATION_V2.md)를 적용한다.

직접 관리회사의 작은 목록으로 시작하면 데이터 출처와 종료 확인 책임은 명확해질 수 있지만 선택 편향과 물량 부족은 남는다. 한 공급사의 한 구간 검증이 통과해도 세 도시 전체 시장을 대표한다고 표시하지 않는다. 실제 공급이 충분하지 않으면 판단을 보류하고 두 번째 독립 원청을 추가한다.
