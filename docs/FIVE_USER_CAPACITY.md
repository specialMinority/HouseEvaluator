# 동시 이용 5명 운영 기준

5명이 각각 검색 또는 URL 조회 1건을 동시에 요청하는 사용 흐름을 지원한다. 화면 접속 인원 수를 제한하거나 사람 수를 식별하는 기능은 없다. 검색과 URL 조회를 합쳐 최대 5개 작업을 접수하고 원문 조회는 순차 실행한다. 6번째 진행 요청에는 혼잡 응답을 반환한다.

대기와 실행 합계는 최대 450초, 개별 실행권은 75초다. 원문 검색 자체의 45초·URL 읽기의 8.5초 제한은 유지한다. 첫 요청도 작업자 확인 주기에 따른 대기가 있으며, 뒤에 있는 사용자는 수 분 기다릴 수 있다. 화면에는 앞선 요청 수를 표시한다. 취소된 실행도 이미 시작한 원문 작업이 종료될 때까지 순서에 포함한다.

상태 확인을 5초 간격으로 제한해 5명 기준 약 60회/분을 사용한다. API의 기존 120회/분 한도 안에 등록·비교 요청 여유를 남긴다. 브라우저 탭 추가, 연속 클릭 외 추가 API 호출, 공유 프록시의 다른 요청까지 무제한으로 수용한다는 의미는 아니다.

전 이용자 합산 검색 30회/시간, URL 조회 60회/시간, 합계 240회/24시간이다. 원문 연결은 60회/분·1,200회/시간·6,000회/24시간이며 한 검색이 여러 연결을 소비한다. 이 값은 보호 상한이며 완료 처리량을 보장하지 않는다. 실패한 실제 조회도 포함한다. 사용량은 기존 전용 볼륨에 유지한다.

PC의 파일·네트워크 격리, 허용 호스트와 URL 제한, DNS 검사, TLS 검증, 원문 연결 시간·크기·분당 한도, CPU·메모리 한도를 유지한다. 새 방문자 추적 또는 검색 조건 저장 기능은 추가하지 않는다.

## 검증

로컬 합성 응답 검증: 5개 동시 HTTP 접수·60회 상태 조회·5개 비교 모두 성공. 실행당 74초의 가상 시계 지연에서도 5개가 순차 완료했다. 브라우저에서 5번째 대기 순서와 150초 경과 후 계속 대기·완료를 확인했다. 전체 회귀 **1,479 passed, 1 skipped, 468 subtests passed** (169.89초), JavaScript 구문 검사 통과. 건너뛴 테스트는 기존 Windows 심볼릭 링크 권한 제약이다.

실제 배포 검증은 배포 후 별도로 기록한다. PC·Docker·로그인·인터넷 연결이 필요하며 원문 사이트 차단이나 Render 재시작 시 완료를 보장하지 않는다.
