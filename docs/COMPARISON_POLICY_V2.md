# 직접 비교 정책 v2.0

이 문서는 `backend/v2/comparison.py`의 구현 계약이다. 초기 정책은 시장 검증 결과가 아니다. 서버 운영자가 검증 보고서에 연결한 `도시/평면` 구간만 실제 가격 방향 판정을 활성화할 수 있다. 기본값은 승인 구간 없음이다. 합성 데이터는 승인 설정과 관계없이 항상 `limited`, `judgment: null`이다.

## 1. 입력과 관측 신뢰성

- 도시: 도쿄·오사카·후쿠오카. 지원하지 않는 도시·평면 등은 `ValidationError`다.
- 월 기본비용은 월세 + 관리비다. 관리비 미상은 0엔으로 바꾸지 않는다.
- 구조·건축연도·역 도보·층·욕실 분리·가구 여부·관리비를 모르면 입력 대상의 결과는 `insufficient`다. 방향은 약한 조건으로 분리하여 미상을 표시한다.
- 현재 모집 중이고, 모집 상태 확인 시각이 평가 시각 기준 24시간 이내인 관측만 사용한다. 24시간 경계는 포함한다. 미확인 상태·미래 시각·모집 종료·신청 중·오래된 관측을 제외한다. 다운로드 시각을 상태 확인 시각으로 대입하지 않는다.
- 공급원 메타데이터가 전달되면 비교·표시·보관 권한과 유효기간을 매번 확인한다. 미등록·만료·불완전·합성/실측 모드 불일치 공급원은 사용할 수 없다. 메타데이터 없는 직접 라이브러리 호출은 `source_rights_unverified`로 표시한다. HTTP 경로는 항상 저장소의 공급원 메타데이터를 전달한다.
- 실측과 합성 관측은 어떤 경우에도 섞지 않는다. 이름 없는 공급원에 가상의 업체명을 붙이지 않는다.

## 2. 자기 매물 및 중복 제거

수입자가 제공한 정규 호실 ID와 건물 ID가 식별 기준이다. 문자열 앞뒤 공백만 정리하고 역 이름 부분 일치나 주소·가격으로 ID를 추측하지 않는다. 대상 호실 ID가 있으면 모든 공급원·URL의 동일 호실을 제외한다. 대상 호실 ID 없이 건물 ID만 있으면 그 건물 전체를 보수적으로 제외한다. 둘 다 없으면 `identity_unverified`이고 가격 방향을 판정하지 않는다.

같은 호실·공급원·모집 ID의 이력은 수신 시각이 가장 최신인 관측으로 먼저 결정한다. 그 뒤 모집 상태와 최신성을 검사한다. 따라서 최신 관측이 오래되거나 종료되어도 예전 활성 관측이 복원되지 않는다. 동일 수신 시각의 모집 상태·가격·조건이 충돌하면 해당 호실을 제외한다. 여러 공급원의 현재 유효 관측에서 활성/비활성 상태가 충돌하거나 활성 가격·조건이 충돌해도 해당 호실을 제외한다. 일치하는 여러 게시물은 호실 1개로 집계하고 가장 최신 관측의 출처를 남긴다.

`excluded_counts`는 원본 관측/게시물 또는 정규화 호실이 제외된 해당 처리 단계의 개수다. 혼합 단위이므로 원본 행 수와 단순 합계로 맞추는 통계가 아니다. `sample`은 최종 고유 호실·건물 수다.

## 3. 비교 조건과 완화

항상 유지하는 조건은 도시·지자체·정확한 역 ID·평면·구조·건물 종류·계약 종류·가구 여부·욕실 분리다. 건축연도 기준 현재 연도와의 차이가 1년 이하인 신축 여부도 반드시 같다. 완공 월일은 원본에 없으므로 연도 기준 신축 구분이며 이를 정밀 준공연령으로 해석하지 않는다.

층 구간은 지하(0 이하), 1층, 2~5층, 6~10층, 11층 이상이다. 층 구간은 완화하지 않는다. 초고층·최상층 여부 등 계약 밖의 정보는 추정하지 않는다.

처음에는 면적 ±max(1㎡, 5%), 건축연도 ±2년, 도보 ±2분, 알려진 방향 일치다. 이후 다음 조건을 하나씩만 바꾸며 목표 표본에 도달하면 멈춘다.

1. 방향: 제한 해제. 방향 미상도 명시적으로 포함할 수 있다.
2. 면적: ±10%까지. 10㎡ 미만인 극소형의 초기 1㎡ 범위는 줄이지 않으므로 `max(초기 범위, 10%)`다.
3. 건축연도: ±5년, 신축 경계 유지.
4. 도보: ±5분.

후보를 가격으로 정렬하여 자르거나, 입력 월세에 근접한 후보를 찾지 않는다. 최종 조건 안의 모든 적격 호실을 사용한다. 단계별 이전/이후 조건과 후보 수, 실제 조건 차이, 결측을 결과에 남긴다. 부족해도 다른 역·구조·평면이나 과거 평균으로 전환하지 않는다.

## 4. 하나의 가중 분포

건물 수 B, 해당 건물의 후보 호실 수 n_b에 대해 각 호실의 최종 가중치는 `w_i = 1/(B × n_b)`다. 전체 합은 1, 건물별 합은 1/B다. 한 건물의 많은 호실이 분포를 지배하지 않는다. 유효 표본 수는 동일 가중치의 `1 / Σw_i²`다. 조건 적합성·최신성은 이 가중치로 타협하지 않고 앞 단계에서 통과해야 한다.

대표가격은 이 분포의 Q50이다. Q25/Q50/Q75 모두 동일한 가격과 가중치를 쓴다. 가중치가 모두 같으면 Hyndman–Fan type 7 선형 보간을 사용하므로 짝수 표본의 중앙값은 가운데 두 값의 평균이다. 가중치가 다르면 가격순 관측의 `p_i = Σ_{j<i}w_j + w_i/2` 지점 사이를 선형 보간한다. 양끝 밖에서는 끝값을 사용한다. 가격 동률은 호실 ID로 결정적 정렬한다.

가중치·분위수 중간 계산에는 유리수를 사용한다. 엔 금액은 가장 가까운 정수로 반올림하며 정확한 .5는 올린다. 차액과 비율은 화면에 반환한 동일 대표가격에서 계산한다. 비율은 소수점 8자리, 유효 표본 수는 6자리로 표시한다. 표본 통과 판정에는 반올림 전 유효 표본 수를 사용한다.

## 5. 결과 상태

| 상태 | 조건 | 가격 요약 | 방향 판정 |
|---|---|---|---|
| comparable | 20호실·10건물·유효 표본12 이상, 대상 식별, 핵심 입력 완전, 운영자 검증 승인, 실측 | 제공 | 가능 |
| limited | 최소 10호실·5건물·유효 표본8 이상이나 충분 기준/식별/검증 부족 또는 합성 | 참고값 제공 | 항상 null |
| insufficient | 핵심 입력 결측 또는 최소 표본 미달 | 모두 null | null |
| stale | 최종 현재 후보가 없고 동일 고정조건의 모집 중 오래된 관측이 존재 | 모두 null | null |

검증 승인 없이 `policy_unvalidated` 사유가 반드시 나온다. 비교 가능 상태에서 대상 비용이 Q75보다 높고 대표가격보다 5% 이상 높으면 higher, Q25보다 낮고 대표가격보다 5% 이상 낮으면 lower, 나머지는 similar다. 5%는 기획서의 제품 가설이며 검증 없이는 실제 판정에 쓰이지 않는다. 사분위 범위는 개별 모집가격 가운데 50%의 요약이지 적정가 신뢰구간이나 계약가격 보장이 아니다.

공급원이 하나면 공급 범위 제한을 표시한다. 독립 공급원 ID가 없으면 독립성 미검증을 표시한다. 표본 수가 많다는 사실만으로 지역 시장 전체를 대표한다고 주장하지 않는다.

## 6. 재현성과 범위

`assessment_id`는 정규화된 대상, 모든 입력 관측(제외 관측 포함), 공급원 메타데이터, 평가 시각, 스냅샷 버전, 합성 모드, 승인 구간 집합, 전체 수치 정책의 SHA-256이다. 배열 순서는 결과나 ID를 바꾸지 않는다. 동일 입력과 시각은 동일 결과다. 시각·상태·권한·가격·검증 설정·정책 변경은 평가 ID를 바꾼다.

이 엔진은 공급권, 정규 ID 매핑, 시장 검증을 만들어내지 않는다. 운영자는 허가된 완결 스냅샷과 검수된 정규 ID를 제공해야 한다. 정책 변경 시 정책 버전과 오프라인 검증 보고서도 갱신해야 한다.
